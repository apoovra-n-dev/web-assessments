# CSS Grid Layout Practice

## About

This project is a CSS Grid practice project created to understand and practice **CSS Grid Layout** concepts.

The webpage uses CSS Grid to create a basic website layout with:

- Header / Navigation
- Left Article
- Main Article
- Right Article
- Footer

The layout is created using `grid-template-areas`, which makes it easy to define where each section should appear.

---

## Technologies Used

- HTML5
- CSS3
- CSS Grid

---

## CSS Concepts Practiced

### 1. CSS Grid

The main container is converted into a grid using:

```css
.container {
    display: grid;
}
