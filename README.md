# Web Personal Portfolio

## About

This project is a personal portfolio website created to showcase my skills, education, projects, and contact information.

## Technologies Used

- HTML5
- CSS3

## Features

- Home section
- About section
- Skills section
- Projects section
- Education details
- Contact section
- Responsive design
- Simple and clean user interface

## Project Sections

### Home
Introduces me and provides a short overview of my profile.

### About
Contains information about my education and background.

### Skills
Displays my technical skills such as:
- Core Java
- HTML
- CSS
- JavaScript
- SQL
- Spring Boot

### Projects
Showcases my completed projects with project details.

### Education
Displays my educational qualifications.

### Contact
Provides contact information for communication.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
