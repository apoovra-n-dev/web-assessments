# CSS Navigation Hover Effect Practice

## About

This is a simple CSS practice project created to understand and practice CSS navigation bars, inline-block elements, hover effects, box shadows, transitions, spacing, and styling.

The project contains a dark-themed navigation bar with **Home, Contact, and About** links.

When the user moves the mouse over a navigation link, a glowing white box-shadow effect appears around the link.

## 🛠️ Technologies Used

- HTML5
- CSS3

## Features

- Dark-themed navigation bar
- Inline-block navigation links
- Rounded navigation buttons
- Hover glow effect using `box-shadow`
- Smooth transition effect
- Responsive viewport-based main section
