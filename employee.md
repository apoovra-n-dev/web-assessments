# Employee Management Dashboard

## 📌 About the Project

A simple **Employee Management Dashboard** built using **HTML, CSS, and JavaScript**.

This project demonstrates fundamental JavaScript concepts including variables, data types, functions, operators, decision-making statements, higher-order functions, callbacks, and salary calculations.

## 🚀 Features

- Employee data management
- Total employee calculation
- Active employee calculation
- Inactive employee calculation
- Average salary calculation
- Employee salary classification
- Employee eligibility checking
- Annual salary calculation
- Salary increment calculation
- Higher-order function implementation
- Employee summary generation
- Responsive dashboard UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
