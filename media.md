# CSS Absolute Positioning & Media Queries Practice

## About

This project is a simple CSS practice project created to understand and practice:

- CSS `position: absolute`
- `left` property
- CSS `@media` queries
- `min-width`
- Responsive design basics
- Different styles based on screen width
