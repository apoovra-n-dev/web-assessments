# Todo Application

A simple Todo Application developed using HTML, CSS, and JavaScript. The application allows users to add, complete, delete, search, and manage their tasks.

## Features

- Add new tasks
- Display task list
- Mark tasks as completed
- Delete tasks
- Search tasks
- Display total task count
- Store tasks using Local Storage
- Retrieve tasks after refreshing the page
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
