# CSS Flexbox Practice

## About

This project is a CSS Flexbox practice project created to understand and
practice different Flexbox properties.

Multiple containers are used to experiment with Flexbox alignment, direction,
wrapping, ordering, growing, shrinking, and individual item alignment.

## Technologies Used

- HTML5
- CSS3

## Flexbox Concepts Practiced

- `display: flex`
- `flex-direction`
- `justify-content`
- `align-items`
- `align-self`
- `flex-wrap`
- `flex-wrap: wrap-reverse`
- `flex-direction: column-reverse`
- `flex-grow`
- `flex-shrink`
- `flex-basis`
- `order`
