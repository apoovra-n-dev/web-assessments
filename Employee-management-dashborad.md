
# Employee Management Dashboard

## Description
Employee Management Dashboard is a simple web application created using HTML and CSS. It helps to display and manage employee-related information in a structured dashboard layout.

## Features
- Dashboard summary
- Total employees count
- Active employees count
- Inactive employees count
- Average salary information
- Employee registration form
- Employee details section
- Salary summary section
- Employee status section
- Sidebar navigation
- Smooth scrolling navigation

## Technologies Used
- HTML5
- CSS3
