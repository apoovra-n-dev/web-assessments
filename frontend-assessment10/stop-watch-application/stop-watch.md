# Stopwatch Application

A simple Stopwatch Application developed using HTML, CSS, and JavaScript. The application allows users to start, stop, reset, and track elapsed time.

## Features

- Start the stopwatch
- Stop/Pause the stopwatch
- Reset the stopwatch
- Display elapsed time
- Real-time time updates
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
