# CSS Animation, Gradients & Background Practice

## About

This project is a CSS practice project created to understand and practice CSS animations, keyframes, gradients, background images, and element positioning.

A circular ball is animated around a square box using CSS `@keyframes`.

During the animation, the ball changes its background using different types of gradients and an image.

## Technologies Used

- HTML5
- CSS3
