# Contact Manager

## About the Project

Contact Manager is a simple web application built using **HTML, CSS, JavaScript,Bootstrap and REST API concepts**.

The application allows users to manage contacts by performing basic **CRUD operations** such as creating, reading, updating, and deleting contact information.

## Features

- Add new contacts
- View contact details
- Edit existing contacts
- Delete contacts
- Search contacts
- CRUD operations using API
- Responsive user interface
- Form validation
- Bootstrap-based styling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- REST API
- JSON
