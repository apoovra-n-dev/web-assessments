# Employee Management System

A simple and responsive Employee Management System built using HTML, CSS, JavaScript, and JSON Server.

This project allows users to manage employee records with CRUD operations, search, filtering, sorting, validation, and status management.

## Features

- View all employees
- Add new employees
- Edit employee details
- Delete employees with confirmation
- Toggle employee status
- Search employees by name or email
- Filter employees by department
- Sort employees by name, department, or joining date
- Form validation
- Responsive design
- Dashboard statistics
- REST API integration using JSON Server
- Error handling for API requests
- Modal-based Add/Edit/Delete operations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON Server
- REST API
- Git & GitHub
